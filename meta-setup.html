COLLEGA FACEBOOK + INSTAGRAM

Questa pagina non salva token nel repository e non li invia a Open Social Scheduler. Il token che incolli viene usato solo nel tuo browser per interrogare direttamente Meta Graph API.

PASSO 1

Genera un User Access Token Meta

Apri Graph API Explorer, seleziona l'app Meta F1 e genera un User Access Token con questi permessi:

pages_show_listpages_read_engagementpages_manage_postsinstagram_basicinstagram_content_publish
APRI GRAPH API EXPLORER

Nel Graph API Explorer usa il tuo account che amministra la Pagina F1 Immobiliare. Non incollare il token in chat, issue GitHub o file.

PASSO 2

Leggi Pagina e Instagram collegato

In attesa del token.
PASSO 3

Scegli la Pagina F1

Il sistema mostra le Pagine che Meta restituisce al tuo utente. Scegli la Pagina F1 Immobiliare collegata al profilo Instagram corretto.

Nessuna pagina caricata.
PASSO 4

GitHub Secrets da inserire

Quando scegli la Pagina, questi tre valori vengono compilati. Usa i pulsanti COPIA e incollali in GitHub → Settings → Secrets and variables → Actions → New repository secret.

APRI GITHUB SECRETS APRI CHECKLIST #14

I tre valori non devono mai essere committati. `F1_FACEBOOK_PAGE_ACCESS_TOKEN` e `F1_INSTAGRAM_ACCESS_TOKEN` possono coincidere quando usi Instagram API con Facebook Login e il Page Access Token restituito da Meta.
