# Real Media Pro — caricamento manuale foto

Carica qui le immagini che vuoi far usare al motore Real Media Pro.

Formati accettati: JPG, JPEG, PNG, WEBP.
Dimensione minima consigliata: 1080x1350 o superiore.

Le immagini caricate qui hanno priorità sulle immagini trovate automaticamente online.
Il motore evita di ripetere la stessa immagine nello stesso ciclo e registra l'uso in `publisher/image_history.json`.
